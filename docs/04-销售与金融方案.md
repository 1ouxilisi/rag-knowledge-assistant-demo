# 销售与金融方案（演示样例数据）

> 说明：本文件为本地 Demo 演示用样例，价格、利率和政策以门店当期报价和金融机构审批结果为准，AI 不报价、不承诺审批结果。

## 常见购车金融方案
- 全款购车：一次性支付车款，无利息，手续最简单。
- 分期贷款：首付比例和期数可选，月供与利率由金融机构根据个人征信审批确定。
- 厂家金融贴息：部分车型厂家提供阶段性贴息或低息方案，活动期限和车型以当期政策为准。
- 融资租赁（以租代购）：先租后购，适合征信或首付暂不充足的客户，具体条款需仔细阅读合同。

## 报价构成
- 车辆成交价、保险、上牌费、金融服务费、选装配件等分项列明。
- 最终落地价以门店盖章报价单为准，AI 提供的金额仅为示例区间，不能替代正式报价。

## 购车常见材料
- 身份证明、驾驶证、收入或银行流水、征信授权；分期客户按金融机构要求补充材料。
- 旧车置换需提供车辆登记证书、行驶证等，置换补贴以厂家当期政策为准。

## 销售话术边界
- 不夸大续航、不承诺低于政策的折扣、不保证贷款一定通过。
- 价格、优惠、交付周期等敏感问题，统一引导到门店销售顾问出具正式方案。
- 客户投诉、合同争议和特殊审批，转人工顾问处理。
